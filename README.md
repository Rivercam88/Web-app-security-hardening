# Web-app-security-hardening
This project focused on identifying and mitigating vulnerabilities within a WordPress environment uising ModSecurity WAF, Apache reverse proxy hardening, SSL offloading, and traffic filtering techniques. 

## Technologies Used
- ModSecurity WAF
- Apache Reverse Proxy
- WordPress
- SSL Offloading

## Project Tasks 
- Assisted with web application hardening
- Reviewed remediation strategies
- Configured security tools and monitoring
- Participated in vulnerability analysis
- Documented security findings and recommendations
